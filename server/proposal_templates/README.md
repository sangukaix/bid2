# 제안서 템플릿

회사가 업로드한 문서는 디자인 원본이 아니라 회사의 실적, 역량과 강점을
찾는 참고자료로 사용합니다. 새 제안서는 아래 Bid2 템플릿 중 하나로
생성합니다.

- `default.pptx`: 공공기관 제안에 어울리는 안정적인 기본형
- `modern.pptx`: 여백과 대비를 강조한 간결한 전문형
- `public_standard.pptx`: 요구사항, 평가항목, 수행체계 중심의 공공입찰 실무형

각 템플릿의 기본 슬라이드를 바탕으로 AI가 공고에 맞게 약 30장으로
구성합니다.

`proposal_generation_rules.json`에는 검토한 제안서 448쪽에서 정리한 공통
구조, 업종별 목차와 글자 수 기준을 저장합니다. 원본 참고 제안서는 개인정보와
용량 문제로 프로젝트에 보관하지 않습니다.
